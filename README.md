# 🛡️ AI Log Anomaly Detection System

AI-powered log monitoring and anomaly detection platform built using Flask, PostgreSQL, and Isolation Forest.

## 🚀 Live Demo

https://ai-log-anomaly-detection-z3zg.onrender.com

## 📌 Features

- User Authentication
- AI-Based Log Anomaly Detection
- Real-Time Dashboard
- PostgreSQL Database Integration
- Login Tracking
- Search Logs
- Interactive Charts
- Cloud Deployment on Render
- Responsive Design

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- Chart.js

### Backend
- Flask
- Python

### Database
- PostgreSQL (Aiven)

- Isolation Forest (Scikit-learn)
